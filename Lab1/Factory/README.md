Код в Factory не создаёт Circle, Square или Triangle напрямую, а обращается к фабрике, которая возвращает общий интерфейс Shape.
Так же коду не обязательно знать, какую конкретно фигуру мы создаём, метод для создания фигуры:
  public static Shape CreateShape(string type)
Этот метод возвращает значение типа Shape, поэтому он сработает для любой фигуры, что реализовала интерфейс Shape.


Фабрика внутри себя создаёт конкретные объекты, но наружу возвращает их как Shape
